### 11.1 N12 新算法（决议#7 授权内三方自算；**结构定稿、数字等 G-probe**——三方全签）

```
score_i = w1·tier先验_i + w2·rel_norm_i + w3·q_i
q_i     = EMA(yield, latencyOk, novelty(条目级), snippetRate)      // 冷启动 q=1.0
quota   = γ 加权 largestRemainder + 单家份额上限 cap(起点 40%, 待复核) + ε 探索位
ε_total = min(冷启动家数, max(1, round(limit × ε_rate))), ε_rate ∈ [10%, 20%] 待 G-probe
          且 冷启动家数 ≥2 时 ε_total ≥2（三方全签）; limit<10 不开
```

1. **三层信号分工**（取代"固定样板×f"）：
   - `tier先验`：general 1.0／垂类 covers 命中 0.8／其余 0.5——吃现成 `engineTier`（`ws-engines.js:560-566`）+`ENGINE_PROFILE`（:483-485），**不点名任何一家**；
   - `rel_norm`：`rel`=query 词∩(title+snippet) 词数占比（CJK 单字、ASCII 分词），取该家**前 3 条均值**（各家原生名次即相关性序，`:402-403`）；**必须引擎内归一化**（除以该家自身最大值）。依据=0e7b5265 同题中英对照实测（**单窗、裸 rel 口径、待二窗复算**）：**裸 rel 测的是语种不是质量**（pubmed 英文串 rel 仅 5%、arxiv 57%；归一化后 arxiv 25→85%、crossref 45→69%、bing 51→75%）。⇒ **rel_norm 只作同层微调，主骨架=tier×yield×snippetFill×novelty**，否则 P1 v3 专修的"nvd 恒 0 配额"病灶（`:619-620`）在语种维度复活；
   - `q_i`：无点击信号下"质量"的唯一现实口径=可观测代理四件套，跨查询档案驱动。**latency 不进质量、只进 A-1／A-9**（慢≠差：pubmed 1.3–1.5 s 却是医学查询唯一权威）；`novelty` 按**条目级**（"这 URL 是否只有这家给"）——0e7b 实测抄家在全局 URL 去重（`:775-779`）下只能捡漏，引擎级会误伤"多家都给同一权威页"。
2. **废除清单**（三方全签）：`isMain` 硬编码（`:639`／`:652-659`／`:711`）、定量 reserve"专业 4／bing 2／百度 2"（`:641-660`）、"百度不通→bing 补 5"手工规则全废。真理由三条（不靠污染数据）：①点名本身违反决议#7 表现驱动，是"把示例当常量"的残留；②手工规则不随实测更新（预设 bing 恒优）；③**档案缺失（`ENGINE_STATS` 全盘 0 命中）才是"只能点名"的根因** ⇒ 档案落地才有替代物。
3. **cap 只设单家上限、不设主力合计下限**（三方全签）：0e7b 曾主张"bing+baidu ≥60%"，自查**分母算错**后撤回（同口径复算 50/80=63%，高于现状 46%；真实风险=裸 rel 下 baidu 单家可吃 34–43/80 的**通吃**，非塌方）。cap 三档实测（cap30→rel 64.6%／cap40→68.1%／cap60→70.4% 单家最大 43%）系 **0e7b 单窗、已作废的裸 rel 口径、未二窗复算 ⇒ 降为参考值，不作定稿依据**；**起点 40% 保留、标"待 G-probe 用 rel_norm 口径复核"**。
4. **冷启动与探索 ε（形状定稿、数值待测）**：公式见上（v4 的"写死 10%"按 §11.0″①② 降级为 ε_rate 区间；"家数 ≥2 时至少 2 席"=0e7b 提案——limit=10 且 3 家新卡时纯总预算式只给 1 席，两家新卡永远拿不到首批数据；**389 22:2x 逐格复算分叉表后追认**）。其余已签：limit<10 不开；样本<n_min=5 才占位；探索集合内 round-robin；观察两轮后转正；新引擎冷启动 q=1.0 ⇒ 解 C-7 实验 A"接而不变"死结。**先结构后数字**=三方一致。

1. `inspect.signature(r.get)` 里**没有** `allow_redirects` 形参，但传了生效 ⇒ 走 `**kwargs` 透传。开关可用，但属**非显式契约**，升级 curl_cffi 有小概率变脸。
2. 生产 payload 用 `resp.text`，重定向后的目标内容会**原样进正文并报 `ok:true`**，无任何告警——与 fast 腿同一种"静默跟进去"的行为。
